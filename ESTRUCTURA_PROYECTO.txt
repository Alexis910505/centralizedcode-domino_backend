═══════════════════════════════════════════════════════════════
                      MÓDULOS PRINCIPALES
═══════════════════════════════════════════════════════════════

1. 🧑‍💼 AUTENTICACIÓN Y USUARIOS
   ├── Registro con validación
   ├── Login con JWT
   ├── Gestión de perfiles
   ├── Sistema de fichas virtuales
   ├── Bonus diario (100 fichas/24h)
   └── Estadísticas y ranking

2. 🏠 GESTIÓN DE SALAS
   ├── Crear salas (públicas/privadas)
   ├── Códigos únicos de sala
   ├── Unirse/salir de salas
   ├── Sistema de "ready"
   ├── Control de 2-4 jugadores
   └── Auto-limpieza de salas

3. 🎲 MOTOR DE JUEGO
   ├── Generación de 28 fichas
   ├── Reparto aleatorio (7 fichas/jugador)
   ├── Validación de jugadas
   ├── Sistema de turnos
   ├── Detección de ganador
   ├── Detección de tranca
   └── Cálculo de puntos

4. 💰 SISTEMA DE APUESTAS
   ├── Validación de apuestas
   ├── Descuento al inicio
   ├── Distribución de ganancias
   ├── Sistema de bote (pot)
   ├── Registro de transacciones
   └── Actualización de estadísticas

5. 🔌 SOCKET.IO
   ├── Autenticación con JWT
   ├── Eventos de sala
   ├── Eventos de juego
   ├── Notificaciones en tiempo real
   ├── Manejo de desconexiones
   └── Broadcast a jugadores

6. 🗄️ BASE DE DATOS
   ├── Modelo User (usuarios)
   ├── Modelo Room (salas activas)
   ├── Modelo Match (historial)
   └── Modelo Transaction (fichas)


═══════════════════════════════════════════════════════════════
                    ENDPOINTS DE LA API
═══════════════════════════════════════════════════════════════

AUTENTICACIÓN (4 endpoints)
├── POST   /api/auth/register          # Registrar usuario
├── POST   /api/auth/login             # Iniciar sesión
├── POST   /api/auth/logout            # Cerrar sesión
└── GET    /api/auth/profile           # Obtener perfil

USUARIOS (5 endpoints)
├── GET    /api/users/:id              # Obtener usuario
├── PATCH  /api/users/profile/update   # Actualizar perfil
├── POST   /api/users/daily-bonus      # Reclamar bonus
├── GET    /api/users/betting/stats    # Estadísticas de apuestas
└── GET    /api/users/leaderboard/top  # Ranking de jugadores

SALAS (5 endpoints)
├── GET    /api/rooms                  # Listar salas
├── POST   /api/rooms/create           # Crear sala
├── GET    /api/rooms/:code            # Obtener sala por código
├── POST   /api/rooms/:id/join         # Unirse a sala
└── POST   /api/rooms/:id/leave        # Salir de sala

PARTIDAS (3 endpoints)
├── GET    /api/matches/history/:userId    # Historial de usuario
├── GET    /api/matches/:id                # Detalle de partida
└── GET    /api/matches/stats/general      # Estadísticas generales

                  EVENTOS SOCKET.IO
═══════════════════════════════════════════════════════════════

CLIENTE → SERVIDOR
├── join_room           # Unirse a sala
├── leave_room          # Salir de sala
├── ready               # Marcar como listo
├── start_game          # Iniciar partida (host)
├── play_tile           # Jugar una ficha
└── pass_turn           # Pasar turno

SERVIDOR → CLIENTE
├── connected           # Conexión exitosa
├── room_joined         # Sala unida exitosamente
├── player_joined       # Nuevo jugador en sala
├── player_left         # Jugador salió
├── player_ready        # Jugador listo/no listo
├── all_ready           # Todos listos
├── game_started        # Partida iniciada
├── tiles_dealt         # Fichas repartidas
├── tile_played         # Ficha jugada
├── turn_passed         # Turno pasado
├── game_ended          # Partida terminada
└── error               # Error en operación
