═══════════════════════════════════════════════════════════════
                     FLUJO DE TRABAJO
═══════════════════════════════════════════════════════════════

1. NUEVA FUNCIONALIDAD
   ┌─────────────────────────────────────────────┐
   │ develop → feature/mi-feature → develop     │
   └─────────────────────────────────────────────┘

   git checkout develop
   git pull origin develop
   git checkout -b feature/mi-nueva-funcionalidad
   # ... desarrollar ...
   git add .
   git commit -m "feat: agregar funcionalidad X"
   git push origin feature/mi-nueva-funcionalidad
   # Crear Pull Request en GitHub


2. PREPARAR PARA STAGING
   ┌─────────────────────────────────────────────┐
   │ develop → staging (via Pull Request)       │
   └─────────────────────────────────────────────┘

   # En GitHub: Crear PR de develop → staging
   # QA y testing en staging
   # Aprobar y merge


3. DESPLEGAR A PRODUCCIÓN
   ┌─────────────────────────────────────────────┐
   │ staging → main (via Pull Request)          │
   └─────────────────────────────────────────────┘

   # En GitHub: Crear PR de staging → main
   # Validación final
   # Aprobar y merge
   # Tag de versión


4. HOTFIX URGENTE
   ┌─────────────────────────────────────────────┐
   │ main → hotfix/bug → main + develop        │
   └─────────────────────────────────────────────┘

   git checkout main
   git checkout -b hotfix/bug-critico
   # ... corregir ...
   git push origin hotfix/bug-critico
   # Merge a main Y develop


═══════════════════════════════════════════════════════════════
                    CONVENCIONES DE COMMITS
═══════════════════════════════════════════════════════════════

feat:      Nueva funcionalidad             ✨
fix:       Corrección de bug               🐛
docs:      Cambios en documentación        📝
style:     Formato, punto y coma           💄
refactor:  Refactorización                 ♻️
test:      Tests                           🧪
chore:     Tareas de mantenimiento         🔧

Ejemplos:
  git commit -m "feat(auth): agregar OAuth Google"
  git commit -m "fix(socket): corregir desconexión"
  git commit -m "docs(readme): actualizar instalación"
