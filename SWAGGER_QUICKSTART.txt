                  CÓMO PROBAR TU API (5 pasos)
═══════════════════════════════════════════════════════════════

PASO 1: Registrarte
────────────────────
1. Ve a: POST /api/auth/register
2. Click: "Try it out"
3. Edita el JSON:
   {
     "name": "Test User",
     "email": "test@example.com",
     "password": "password123"
   }
4. Click: "Execute"
5. ✅ COPIA EL TOKEN de la respuesta


PASO 2: Autenticar
───────────────────
1. Click en: [Authorize 🔓] (arriba a la derecha)
2. Pega tu token
3. Click: "Authorize"
4. Click: "Close"
5. ✅ Ahora todos los endpoints protegidos funcionan!


PASO 3: Crear una Sala
───────────────────────
1. Ve a: POST /api/rooms/create
2. Click: "Try it out"
3. Edita:
   {
     "bet": 100,
     "maxPlayers": 4,
     "name": "Mi Sala"
   }
4. Click: "Execute"
5. ✅ Sala creada!


PASO 4: Listar Salas
─────────────────────
1. Ve a: GET /api/rooms
2. Click: "Try it out"
3. Click: "Execute"
4. ✅ Verás todas las salas!


PASO 5: Ver tu Perfil
──────────────────────
1. Ve a: GET /api/auth/profile
2. Click: "Try it out"
3. Click: "Execute"
4. ✅ Verás tu información!

═══════════════════════════════════════════════════════════════
                        TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ No se muestra nada en /api-docs
   → npm install swagger-ui-express swagger-jsdoc
   → npm run dev

❌ Endpoints no aparecen
   → Reinicia el servidor
   → Verifica comentarios JSDoc en las rutas

❌ Error 401 Unauthorized
   → Haz login de nuevo
   → Copia el nuevo token
   → Click en "Authorize"

❌ No puedo ejecutar endpoints protegidos
   → Verifica que copiaste bien el token
   → No incluyas "Bearer" en el campo
   → El token debe ser reciente (expira en 30 días)
